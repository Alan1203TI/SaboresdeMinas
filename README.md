Como testar localmente:
1. Extraia o ZIP.
2. Abra o arquivo index.html no Chrome ou Edge.
3. Para testar a instalação PWA, publique no GitHub Pages ou sirva por um servidor local.

Como publicar no GitHub:
1. Crie um repositório novo.
2. Envie todos os arquivos para a raiz do repositório.
3. Vá em Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione a branch main e a pasta /(root).
6. Salve e aguarde o link do GitHub Pages.
